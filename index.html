Componentes clave

La propuesta va más allá de una página web.

E-commerce

Catálogo, variantes, tallas, disponibilidad, pedidos, clientes, cupones, promociones, compra directa y continuidad por WhatsApp.

CRM

Dos caminos: CRM propio para máxima adaptación o CRM externo para implementación más rápida y dependencia de licencias.

WhatsApp + chatbot

API oficial de Meta, trazabilidad, automatizaciones, clasificación inicial y transferencia a asesor humano.

Administración

Admin in-house para control gerencial o integración con Alegra, sin venderlo como reemplazo automático de obligaciones tributarias.

Pasarelas

Bold, Wompi y Mercado Pago se comparan según operación física, digital, API, costos y conciliación.

Métricas

Ventas, leads, conversión, canal, inventario, productos, clientes, recompra y tiempo de respuesta sin inventar históricos.
